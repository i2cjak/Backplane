# Backplane assets

`backplane.svg` is the stacked-board mark used on [backplane.works](https://backplane.works).
The palette is dark olive (`#111410`), warm off-white (`#e6e9de`), and pale green (`#d6edaf`).

Run `vp run icons:export` to render desktop, web, Android, iOS, and widget assets from
that vector. `vp run icons:check` verifies that the checked-in assets match.
The exporter runs on Linux, macOS, and Windows. Production, development, and nightly
use the same mark with distinct backgrounds.
